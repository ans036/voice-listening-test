# Voice listening test

**Take the test: https://ans036.github.io/voice-listening-test/**

A blind A/B listening study for research on speech synthesis. Listeners hear two short recordings of the same sentence and pick the one
that sounds more like a real person. It takes **about 15–20 minutes** in three short parts (normal speed, 1.5 times faster, 2 times
faster), with a break between parts.

## How the test works

- **34 pairs, 5–15 seconds each.** Recording A plays first, then B; listeners can replay either and answer on a 7-point scale from
  "A much more natural" to "B much more natural".
- **Random order.** For every listener the pairs of voices, the sentences, which voice is A or B, and the order of the pairs within each
  part are drawn at random. The recordings are anonymised: file names carry no information about which voice made them.
- **Low effort.** One clear question per screen, automatic playback, a progress bar with the time left, an estimate for each part,
  and keyboard shortcuts on computers (A / B to play, 1–7 to answer, Enter for the next pair).
- **Optional comments.** A free-text box at the end for any feedback.

## Privacy

- No names, e-mail addresses or accounts are needed.
- No IP addresses are recorded. A few multiple-choice questions describe the listener (age band, gender, hearing, how they are listening); every question has a
  "Prefer not to say" option.
- **Each person should take part once,** without any personal questions: the browser keeps a small note that it has taken part, and
  a scrambled device signature (made from general settings such as screen size, language and time zone; it cannot identify
  anyone) is stored with the answers so that repeated entries from the same device can be removed in the analysis.
- Answers are used only for research and reported as group results.
